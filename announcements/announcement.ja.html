PowerRustCOBOL AI 2：Web と Mobile

これまで書いてきた COBOL と、これまで使ってきた Form Designer が、ブラウザーとスマートフォンに対応します。

バージョン 2 では、Desktop プロジェクトに加えて、Web と Mobile の 2 つの プロジェクトの種類が加わりました。File ▸ New Project で選びます。これまでに作成した プロジェクトはすべて Desktop プロジェクトで、そのまま開けます。新機能を紹介します。

できるようになったこと

Web アプリケーション

Build は COBOL を直接 WebAssembly にコンパイルします。ページにインタープリターは不要で、 Web の Build に Rust ツールチェーンも要りません。IDE があらかじめビルド済みのプレーヤーをプログラムの隣に コピーするためです。成果物は dist/web/ にある静的なバンドルで、どの Web サーバーでも公開できます。

モバイルアプリケーション

Android のスマートフォンとタブレット、iOS の iPhone と iPad に対応します。Run は、接続した スマートフォンまたは Android エミュレーターにアプリをビルドしてインストールし、起動して、そのログを Output パネルに表示します。Android のリリース版はご自身の鍵で署名します。iOS では、現在はシミュレーター向けの アプリをビルドできます。

COBOL の Backend

ファイル、データベース、シークレットは、プロジェクトの backend/ フォルダー内で、ネイティブの ランタイム上に置かれます。ページは Backend がエクスポートするプログラムを CALL "NAME" WITH WEBSOCKET LINKAGE で呼び出します。TLS 上の JSON とベアラートークンを使い、 再接続とトークンの更新は自動で行われます。COBOL::SqlDatabase は、 EXEC SQL なしで SQLite、PostgreSQL、MySQL に接続します。

サインインとリンク

Authentication コントロールは、Backend を通じて、Cognito、Keycloak、Entra でサインイン、 サインアップ、パスワードの回復、第 2 要素の確認を行います。Hyperlink コントロールは、 ページ上の本物のリンクです。

CSS3 とレスポンシブなページ

アプリケーション全体のスタイルシートとフォームごとのスタイルシートがページを装飾し、スタイルシートは プロパティより優先されます。既定はシングルページアプリケーションで、独立したフォームページが代替の方式です。

Web ビューでのプレビュー

デザイナーの Preview は、システムの Web ビューでバンドルを表示します。スマートフォン、 タブレット、デスクトップのいずれかのサイズ、向き、ピクセル比、配色、ページの言語を選べます。フォーム、 スタイルシート、Backend を変更すると、開いているページに反映されます。

Canvas とグラフィックス

Canvas 2D、Canvas 3D、そして ImageBuffer、Plot、Scene3D、Physics2D、 Physics3D の各オブジェクトを、すべてのプラットフォームで利用できます。

既定で安全

Build はプロジェクト自身のファイルにシークレットが含まれていないか調べ、見つかると停止します。 バンドルには Content-Security-Policy が付きます。Mobile プロジェクトは証明書をピン留めでき、リリース版の Backend は設定にシークレットを直接書くことを拒否します。

Claude Code と Grace も新しい種類を理解

Claude Code プラグインは、17 のツールと 13 のスキルを備え、Web アプリケーションと Backend 向けのものも 含まれます。IDE のアシスタントである Grace もそれらを理解し、COBOL::SqlDatabase も 理解しています。

中身は同じ COBOL

生成される WebAssembly は、適合性テストによってインタープリターと同じ動作に保たれています。NIST CCVS85 の NC、IF、IC の各モジュールは、生成された WebAssembly 上で失敗ゼロで実行されます。

はじめに

  1. File ▸ New Project を選び、Web（または Android か iOS のデバイス）を選びます。
  2. フォームを開いて Preview を押すと、Web ビューで確認できます。
  3. Backend のプログラムを追加し、backend/exports.toml に登録して、ハンドラーから CALL で呼び出します。
  4. Build を押します。

または、File ▸ Open Project からサンプルを開きます。

対応範囲について（正直に）。 デバイスやストア向けの iOS アプリのリリースアーカイブは、 まだビルドできません。ブラウザーの対応状況は、Chromium とシステムの Web ビューで測定しました。 Mac の Safari と、実機の Android の Web ビューは、まだ測定していません。Web フォームの COBOL は一部の機能に 限られます。ファイル、SQL などサーバー側の処理は Backend の役割で、ページで実行できない行は Build が 知らせます。WebAssembly の仕様の受け入れ基準には、まだ未完了のものがあります。一覧は specs/WASM-OPEN-ACS.md にあります。
