PowerRustCOBOL AI 2.1：新しくなったこと

追加のインストールなしでビルドでき、サーバー向けのパッケージも作れます。最後に公開されたリリース 2.0.613 以降の変更点です。

知っておきたいことは 6 つです。そのほかは短い一覧にまとめました。

新しくなったこと

Rust なしのデスクトップ Build

Build は COBOL を WebAssembly にコンパイルし、あらかじめ用意されたランナーに組み込みます。 実行ファイルは bin/ に 1 つできあがり、サンプルプロジェクトなら 1 秒ほどで、お使いのマシンに Rust は不要です。 Debug ビルド、EXEC RUST、External Crates、そしてまれな一部の構文は、これまでどおり Cargo を通ります。 どちらの経路を使ったか、その理由も Build が表示します。

Rust なしの Backend

Web または Mobile の Backend も同じ方法でビルドします。COBOL が WebAssembly モジュールになり、あらかじめ用意された ランナーがそれを提供します。サンプルの 4 つの Backend は、どちらの経路でも同じ応答を返します（176 回の呼び出しすべてが一致）。 モジュールが対応しないものには Cargo の経路が残り、Backend の設定 build_path でどちらかを指定できます。

サーバー向けの 2 つのファイル

Web プロジェクトの File ▸ Package Project は、アプリケーションとサーバー用のインストール スクリプト（Linux と macOS は .sh、Windows は .ps1）を作ります。スクリプトの引数は nginx の フォルダー 1 つだけで、Backend をサービスとして実行します。何かを書き出す前に、サーバー向けの設定を確認し、 Backend が起動することを確かめます。

別のシステム向けのパッケージ

Package ウィンドウで、サーバーの System を選びます。現在は linux-x86_64 で、Mac や Windows のマシンから作れるので、サーバー上でパッケージ化する必要はありません。このパッケージの Backend は、 用意済みの Linux 用ランナーにあなたのモジュールを結合したものです。コマンドラインでは rcrun package --target を使います。

Preview のアドレスが変わらない

Web または Mobile プロジェクトの Preview と Run は、毎回同じポートでページを提供するので、ブックマークや 開いたままのタブからもう一度アクセスできます。ポートはプロジェクトの設定の Page port (Preview) で指定します。 入力欄に既定値が表示されます。

準備まで整える Windows セットアップ

Windows のセットアップは、Microsoft の C++ ビルドツールがなければインストールし、準備ページで「はい」を選ぶと、 Rust 1.95.0 と PowerRustCOBOL 自身の部品を一度だけコンパイルします。最初の Debug ビルドで、あなたのプログラムだけを コンパイルすれば済みます。Skip を選ぶと、これまでと同じ内容がインストールされます。

細かな変更

  • キャンバスは、マウスポインターを隠し、中央に戻し、Escape を通知できます：Cursor = None、CenterPointer()、onEscapePressed。PowerCallOfDuty はこの 3 つを使っています。
  • LINE SEQUENTIAL ファイルはレコードのバイトをそのまま保持し、Viewer の LoadBytes は ブラウザー上でドキュメントを表示します。
  • Web の Build が書き出す nginx のファイルは、正しく起動し、各ファイルを正しい種類で配信し、セキュリティヘッダーを保ちます。
  • Spatial などの Aurora テーマで、押したツールバーのボタンが押された見た目になります。また macOS では、IDE の ウィンドウのタイトルがウィンドウのボタンの隣に表示されます。
  • クリーンインストールでも、PowerOficina がデータ付きで開きます。

対応範囲について（正直に）。 別のシステム向けのパッケージは Linux x86-64 のみで（Windows サーバー向けは 引き続き Windows 上で作ります）、x86-64 のコンテナーで動作を確認しましたが、実際のサーバーではまだです。ビルド時間は Apple silicon の Mac で測定しました。
