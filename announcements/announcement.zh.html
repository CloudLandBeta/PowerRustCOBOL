PowerRustCOBOL AI 2：Web 与 Mobile

您已经在写的 COBOL，您已经在用的 Form Designer，现在可以用于浏览器和手机。

第 2 版在 Desktop 项目之外，新增了两种项目类型：Web 和 Mobile。请在 File ▸ New Project 中选择。您以前写的所有项目都是 Desktop 项目，可以原样打开。以下是新增内容。

现在您可以做什么

Web 应用程序

Build 将您的 COBOL 直接编译为 WebAssembly：页面中没有解释器，Web 的 Build 也不需要 Rust 工具链，因为 IDE 会把预先构建好的播放器复制到您的程序旁边。结果是位于 dist/web/ 的静态 包，任何 Web 服务器都可以托管。

移动应用程序

支持 Android 手机和平板、iOS 的 iPhone 和 iPad。Run 会在已连接的手机或 Android 模拟器上 构建、安装并启动应用，并在 Output 面板中显示其日志；Android 发布版使用您自己的密钥签名。对于 iOS，目前 可构建用于模拟器的应用。

COBOL Backend

文件、数据库和密钥都位于项目的 backend/ 文件夹中，运行在原生运行时之上。页面通过 CALL "NAME" WITH WEBSOCKET LINKAGE 调用 Backend 导出的程序：基于 TLS 的 JSON 加 bearer 令牌， 重新连接和令牌刷新由系统代劳。COBOL::SqlDatabase 无需 EXEC SQL 即可访问 SQLite、PostgreSQL 和 MySQL。

登录与链接

Authentication 控件通过您的 Backend，借助 Cognito、Keycloak 或 Entra 完成登录、注册、 找回密码和第二因素验证。Hyperlink 控件是页面上真正的链接。

CSS3 与响应式页面

应用程序样式表和每个窗体各自的样式表共同为页面设置样式，并且样式表优先于属性。默认是单页应用程序； 独立的窗体页面是另一种选择。

在 Web 视图中预览

设计器的 Preview 在系统的 Web 视图中显示该包。您可以选择手机、平板或桌面尺寸、方向、 像素比、配色方案以及页面语言；对窗体、样式表或 Backend 的修改会同步到已打开的页面。

Canvas 与图形

Canvas 2D、Canvas 3D，以及 ImageBuffer、Plot、Scene3D、Physics2D 和 Physics3D 对象，适用于所有平台。

默认安全

Build 会扫描项目自身的文件中是否含有密钥，发现后即停止；包中带有 Content-Security-Policy；Mobile 项目 可以固定证书；发布版 Backend 会拒绝在其配置中直接写入的密钥。

Claude Code 和 Grace 也了解这些类型

Claude Code 插件现在有十七个工具和十三个技能，其中包括面向 Web 应用程序和 Backend 的；IDE 的助手 Grace 也了解它们，同样了解 COBOL::SqlDatabase。

底层是同一个 COBOL

生成的 WebAssembly 通过一致性测试与解释器保持相同：NIST CCVS85 的 NC、IF 和 IC 模块在其上运行， 失败数为零。

从这里开始

  1. 选择 File ▸ New Project，然后选择 Web（或一台 Android 或 iOS 设备）。
  2. 打开一个窗体并按下 Preview，在 Web 视图中查看。
  3. 添加一个 Backend 程序，把它列入 backend/exports.toml，然后在处理程序中用 CALL 调用它。
  4. 按下 Build。

或者从 File ▸ Open Project 打开一个示例：

示例展示内容
examples/PowerWebHello最小的 Web 项目：一个带侧边菜单的窗体，以及一个 Backend
examples/PowerMobileHello最小的 Mobile 项目

每个目标需要什么

您要构建您需要
Web 应用程序只需要 IDE
Backend 发布版二进制文件与桌面 Build 相同的工具链：Rust 和平台的链接器
Android 包Android SDK 和 NDK、Java 17 至 21、手机对应的 Rust 目标以及 Tauri 命令行；缺少的每一项，Build 都会指出
用于模拟器的 iOS 应用安装了 Xcode 16 或更高版本的 Mac
如实说明范围。 面向设备或应用商店的 iOS 应用发布归档尚未构建。 浏览器覆盖情况已在 Chromium 和系统的 Web 视图中测量；Mac 上的 Safari 以及真机上的 Android Web 视图尚未测量。 Web 窗体中的 COBOL 只是一个子集：文件、SQL 以及其他服务器端工作属于 Backend，Build 会告诉您哪一行无法在页面中运行。 WebAssembly 规范的部分验收标准仍未完成；清单见 specs/WASM-OPEN-ACS.md。
