# PowerChat sample topics

Installed from **Topics → Install sample topics**, and removed again from the
same form. Nothing here is used until then. Every name, policy and order is
invented for the example.

`samples.txt` lists them, one line each, `|`-separated:

| Line | Fields |
|---|---|
| `TOPIC` | folder, topic name, the topic's system prompt |
| `DOC` | folder, a document in `<folder>/documents/` to import into the topic's Knowledge Base |
| `FILE` | folder, an indexed data file and its `.cidx`, registered for the topic by path (read only) |

Add a topic by adding a folder and its lines — no COBOL changes.
