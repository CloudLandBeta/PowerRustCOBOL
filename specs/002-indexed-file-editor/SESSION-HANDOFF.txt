2. CURRENT UI ARCHITECTURE (Indexed File Editor)
────────────────────────────────────────────────────────────────────────────────

Four-pane layout (when not in raw mode):

+--------------------------------------------------------------------------+
| <toolbar pane>  — indexed_toolbar.rs, vector icons, theme-aware colours  |
+---------------------------------+------------------+---------------------+
| <structure pane>                | <label pane>     | <value pane>        |
| Indexed File Properties (root)  | File name:       | [text inputs...]    |
| > RECORD-NAME                   | PIC:             | [combos...]         |
|     FIELD-1                     | ...              |                     |
+---------------------------------+------------------+---------------------+

Selection → property rows:
  - Indexed File Properties (file): name, assign path, access mode, record
    format, finalized, comments
  - Group field: name, OCCURS, REDEFINES, SYNCHRONIZED, comments
  - Leaf field: name, PIC, length, usage, offset, comments, grid widget

Raw mode: label + value panes hidden; CentralPanel shows COBOL-like text editor.

Theme:
  - apply_opaque_viewport_theme(ctx, current_theme()) each frame in editor/grid
  - current_theme() uses Settings draft theme when Settings form is open
  - Indexed viewports painted BEFORE main apply_glass_visuals in app::update
    (egui 0.29 shares set_visuals globally)
  - glass_panel_frame on structure/labels/values/raw central panels
  - Grid browser also uses opaque viewport theme + glass panel frame
